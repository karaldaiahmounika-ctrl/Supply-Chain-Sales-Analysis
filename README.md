# 📦 Supply Chain Sales Analysis Dashboard (Power BI)

## 📌 Project Overview

This project presents an interactive Supply Chain Analytics Dashboard developed using Microsoft Power BI. The dashboard helps analyze sales performance, inventory management, supplier performance, logistics efficiency, product quality, and demand forecasting to support data-driven business decisions.

---

## 🎯 Objectives

- Monitor overall business performance
- Analyze revenue and profit trends
- Track inventory levels
- Evaluate supplier performance
- Monitor logistics efficiency
- Identify product quality issues
- Forecast future demand

---

- Microsoft Power BI
- Microsoft Excel
- Power Query
- DAX
- Data Modeling
